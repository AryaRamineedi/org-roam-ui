# Legacy reference

This directory contains the original `org-roam-ui` project (Next.js + React
frontend, `org-roam-ui.el` Emacs backend). It is kept **only as a reference**
for the org-ascipio rewrite (see the repo root) — it is not built, run, or
maintained as part of org-ascipio, and none of its code is imported by the
new project. See `../docs/PROTOCOL.md` and the root `README.md` for the new
project.
